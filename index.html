高頻考點 & 必背數值速查

1. 生命表徵正常標準值

  • • 體溫 (T)：36.1–37.5°C（肛探最準發燒>38°C；耳探需往後上方拉直耳道；水銀甩至35°C以下）。
  • • 脈搏 (P)：成人 60–100 次/分（>100 心搏過速；<60 心搏過慢）。
  • • 呼吸 (RR)：成人 16–20 次/分；嬰兒 30–40 次/分。
  • • 血壓 (BP)：理想 <120/<80 mmHg；高血壓前期 120-139/80-89；袖帶需覆蓋上臂長度 2/3。
  • • 血氧 (SpO2)：正常 97–99%（<90% 屬低血氧；抽煙/一氧化碳/嚴重貧血數值可能假性偏高或正常）。

2. 亞太區成年人 BMI 指標

過輕：< 18.5
正常：18.5 – 22.9
過重：23.0 – 24.9
肥胖：25.0 – 29.9
非常肥胖：≥ 30.0

3. 阻力顏色排序（弱 → 強）

• 運動橡筋帶 (Theraband)：
黃 < 紅 < 綠 < 藍 < 黑

• 手部泥膠 (Putty)：
黃 < 橙 < 綠 < 藍 < 紫（紫最強）

4. 儀器核心操作與鐵則

  • • 短波治療 (SWD)：絕對不可有任何金屬（手機、金屬椅等），否則嚴重燒傷！
  • • 超聲波 (US)：切勿空載開機（必須有導電啫喱/水）；輸出頭必須在患處持續打圈。
  • • 干擾波 (IFT)：兩個中頻交變電流聚合，電極必須「對角交叉」擺放。
  • • 蠟療 (Wax)：溫度 52–55°C，浸 5–8 層，敷 15–20 分鐘。
  • • 電療善後順序：治療結束「先關電源，後拆電極」。

5. 臨床與法規必考要點

  • • 轉介：求診物理治療必須有醫生轉介信；助理不可自行診斷或私自建議處方。
  • • 疏忽三要素：照顧責任、失責、造成損失（具因果關係）。
  • • 性罪行查核：不涵蓋私人補習及志願工作者（義工）。
  • • 偏癱轉移：輪椅泊在「健側」並鎖緊；病人用「健側手」支撐；坐穩後「先扣安全帶」。
  • • 運動流程：熱身(10-15m) → 主題(20-30m) → 緩和(5m) → 伸展(5m)。
